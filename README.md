# Student Grade Calculator

A beginner-friendly C program that calculates a student's percentage and grade based on marks in 5 subjects.

## Features

* Accepts student name
* Takes marks for 5 subjects
* Validates marks between 0 and 100
* Calculates percentage
* Assigns a grade
* Displays pass/fail result

## Concepts Used

* Variables and data types
* Arrays
* Loops
* Conditional statements
* Functions
* User input/output

## How to Run

Compile the program using:

```bash
gcc student_grade_calculator.c -o grade_calculator
```

Run it using:

```bash
./grade_calculator
```
